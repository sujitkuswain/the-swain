# The Swain — Hotel Website

## Project
Client hotel website. Currently in UI design/mockup phase for client approval before development.

## Rules

### Responses
- 1-2 lines max. No long explanations unless asked.
- If uncertain, say "I don't know" — never fabricate.
- Don't assume. Ask if something is unclear.

### Git & Infra
- NEVER run `git commit`, `git push`, or `terraform apply` — hooks block these. Propose the command for the user to run manually.
- Always flag cloud cost impact before any infra change.

### Code
- No comments unless the WHY is non-obvious.
- No extra features, abstractions, or error handling beyond what's asked.
- No placeholder/lorem ipsum in final code — only in client mockups.

### Design phase (current)
- Build static HTML/CSS mockups first.
- Get client approval on design before adding any framework/JS complexity.
- Prefer real hotel content placeholders (room names, amenity names) over generic lorem ipsum.
